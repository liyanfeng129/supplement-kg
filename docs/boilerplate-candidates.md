# Boilerplate candidates

Tick `[x]` every line that is boilerplate (it goes on the v4 checklist). Leave real content -- cautions, ingredient forms, claims -- unticked.

Sorted by occurrences. Each line: occurrences (total times the sentence appears) · labels (how many labels contain it) · sentence (normalised) · sample label.

## How these were found

Run on 2026-10-06 over the whole dump; it takes about 30 seconds on 10 cores.

- **Source data:** `datasets/DSLD-full-database-JSON/*/*.json`, the full DSLD
  download: 214,780 raw label records, 659,299 distinct sentences after normalising.
- **Script:** [`docs/boilerplate-candidates.py`](boilerplate-candidates.py). It
  refuses to overwrite an existing output file, so this checklist's ticks are safe.

Steps:

1. **Clean** each raw record with the existing `clean()` from
   `engine/services/dsld_cleaning/service.py` (renderer v3). That gives the segments a
   passage is built from: statement notes and ingredient free text.
2. **Skip the `fullName` segment**, since product names never go on the checklist.
3. **Split each segment into sentences** on `.` `!` `?` `;` or a line break. This
   happens before normalising, which removes the punctuation.
4. **Normalise each sentence** with a sketch of spec 0005's rules: lowercase; remove
   number+unit (`mg`, `mcg`, `iu`, `%`, `capsules`, `servings`, `cfu`, …) and
   standalone numbers, but keep digits touching a letter or hyphen (`b12`); punctuation
   → space; collapse whitespace.
5. **Drop sentences shorter than 15 characters** after normalising, to cut noise such
   as `warning`.
6. **Count** each sentence two ways: *labels* (once per label, however often it
   repeats there) and *occurrences* (every time). The two are close because `clean()`
   already merges identical segments within a label.
7. **Keep the top 400 by occurrences**, each with one label it appears on.

Limits:

- **Frequent is not the same as boilerplate.** Real cautions ("discontinue use two
  weeks prior to surgery", the iron overdose warning) and ingredient forms ("vitamin
  b12 form as cyanocobalamin") are near the top. That is why this list is ticked by
  hand.
- **Normalisation is a sketch, not spec 0005's.** It has no age-limit exception
  ("under the age of" has lost its `18`) and a shorter unit list. A ticked phrase may
  need a small edit to match the final v4 text.
- **Sentence splitting is crude.** Abbreviations break sentences apart, which is why
  `made in the u s a` appears on its own.
- **Only the top 400.** Lower-count variants of the same phrases (other FDA-disclaimer
  wordings, for example) are not shown.
- **The sample label isn't reproducible.** Workers finish in any order, so a rerun can
  pick a different sample label; each one still contains the sentence.
