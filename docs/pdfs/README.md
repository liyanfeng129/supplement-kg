# iDISK papers

Papers from the University of Minnesota group (Rizvi, Vasilakes, Hou, Zhang et al.)
on the integrated DIetary Supplements Knowledge base (iDISK).

## Core: building iDISK

These describe the knowledge base itself and its construction.

| File | Paper |
| --- | --- |
| `2018-rizvi-comparing-ds-resources-amia.pdf` | Rizvi RF, Adam TJ, Lindemann EA, Vasilakes J, Pakhomov SV, et al. **Comparing Existing Resources to Represent Dietary Supplements.** *AMIA Jt Summits Transl Sci Proc* 2018. PMID 29888074 · PMC5961776 — the requirements study that motivated iDISK: compares NMCD, DSID, NHPID, DSLD, LNHPD and finds their DS representation fragmented and inconsistent. |
| `2019-vasilakes-normalizing-ds-product-names-medinfo.pdf` | Vasilakes J, Fan Y, Rizvi R, Bompelli A, Bodenreider O, Zhang R. **Normalizing Dietary Supplement Product Names Using the RxNorm Model.** *MEDINFO 2019*. |
| `2020-rizvi-idisk-jamia.pdf` | Rizvi RF, Vasilakes J, Adam TJ, Melton GB, Bishop JR, Bian J, Tao C, Zhang R. **iDISK: the integrated DIetary Supplements Knowledge base.** *JAMIA* 27(4):539–548, 2020. [doi:10.1093/jamia/ocz216](https://doi.org/10.1093/jamia/ocz216) · PMID 32068839 — the main KB paper. |
| `2020-vasilakes-umls-ds-coverage-jamia.pdf` | Vasilakes J, Bompelli A, Bishop JR, Adam TJ, Bodenreider O, Zhang R. **Assessing the enrichment of dietary supplement coverage in the UMLS.** *JAMIA* 27(10):1547–1555, 2020. [doi:10.1093/jamia/ocaa128](https://doi.org/10.1093/jamia/ocaa128) · PMID 32940692 |
| `2025-hou-ds-rag-llm-jmir.pdf` | Hou Y, Bishop JR, Liu H, Zhang R. **Improving Dietary Supplement Information Retrieval: Development of a Retrieval-Augmented Generation System With Large Language Models.** *JMIR* 27:e67677, 2025. [doi:10.2196/67677](https://doi.org/10.2196/67677) · PMID 40106799 — introduces **iDISK2.0** (refreshed NMCD/MSKCC/DSLD/LNHPD integration) and a RAG system over it. |
| `2025-liu-ds-effects-social-media-chatgpt-amia.pdf` | Liu Y, Hou Y, Yeung J, Thao T, et al. **Identifying Dietary Supplements Related Effects from Social Media by ChatGPT.** *AMIA Jt Summits Transl Sci Proc* 2025. PMID 40502253 · PMC12150709 — uses ChatGPT to extract DS-related effects from social media; iDISK is used as the reference terminology. |
